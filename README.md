# UiLang v1.1

UiLang は Brainf*ck から着想を得た **チューリング完全なジョークプログラミング言語**です。  
本言語は **Brainf*ck との互換性を持ちませんが、対応表を示すことで理解を助けます**。

セルの値は **Unicodeコードポイント** として扱われ、日本語を含む UTF-8 文字を直接出力できます。

本プロジェクトは **非公式・非公認のファンメイド作品** であり、実在の人物・団体・公式プロジェクトとは一切関係ありません。

---

## 特徴

- 🧠 チューリング完全（無限テープ＋ループ）
- 🌏 UTF-8 / Unicode 対応（日本語出力可）
- 🌐 ブラウザで即実行可能
- 💬 命令語以外はすべてコメント扱い
- 🎭 教育用サンプルや冗長コードで学習に最適

## 命令一覧（v1.1）

| 概念 | UiLang 命令 | 説明 | Brainf*ck 対応 |
|----|----|----|----|
| ポインタ右 | はい次〜 | 次のセルへ移動 | `>` |
| ポインタ左 | くぅ〜ん | 前のセルへ移動 | `<` |
| 加算 | ういこらしょ | 現在セル +1 | `+` |
| 減算 | やんのか？ | 現在セル -1（0未満にならない） | `-` |
| 出力 | ういビーム | セル値を Unicode 文字として出力 | `.` |
| 入力 | リスナー募集 | 入力から 1 文字読み込み | `,` |
| ループ開始 | は? | セルが 0 なら対応する ] までジャンプ | `[` |
| ループ終了 | 負けないが？ | セルが 0 でなければ対応する [ に戻る | `]` |
| 基準点生成 | 16歳だぞ | セルに基準値 12354 をセット | n/a |
| 乗算ループ | テトリス<回数>：<加算値>位 | セルに基準値×回数 + 加算値 を加算 | n/a |
| 高頻度差分 | きゃっきゃっ | セルに +10 | n/a |
| 明示ゼロ化 | 寝な！ | 現在セルを 0 にする | n/a |
| 測値ロード | ここで会ったが<数値>年目 | 現在セルに指定値をセット | n/a |

## 言語仕様

- **メモリモデル**  
  - 無限長テープ（実装上は 30,000 セル）  
  - 各セルは **非負整数（Unicodeコードポイント）**  
- **数値はラップしない**（8bit制限なし）  
- **出力**は `String.fromCodePoint` により UTF-8 文字として表示  
- Brainf*ck 既存コードとの互換性は限定的  
- v1.0 仕様コードも **そのまま v1.1 で動作可能**

## サンプルコード

### 最小出力例（可視文字 `!`）

```text
ういこらしょ（33回）
ういビーム
```

## 実行方法
ブラウザで UiLang 実行環境にコードを貼り付けて実行してください。
セルの値やポインタ位置の変化が見える 教育用ビジュアルモード で学習可能です。

### English Note
UiLang is an experimental joke programming language inspired by Brainf*ck, but not fully compatible.
Each memory cell stores a Unicode code point, allowing direct UTF-8 output.
v1.1 adds educational and shorthand instructions to reduce repetitive code.
