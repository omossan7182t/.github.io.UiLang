# UiLang

UiLang は、Brainf*ck 互換の **チューリング完全なジョークプログラミング言語**です。
日本語（UTF-8）のフレーズを命令として使用し、Webブラウザ上で実行できます。

本プロジェクトは **非公式・非公認のファンメイド作品**であり、特定の個人・団体・公式プロジェクトとは一切関係ありません。

---

## 特徴

* 🧠 Brainf*ck 完全互換（チューリング完全）
* 🌏 UTF-8 対応（日本語命令・日本語入出力）
* 🌐 ブラウザのみで実行可能（GitHub Pages）
* 💬 命令以外の文字はすべてコメント扱い
* 🎭 ネタ言語だが仕様は真面目

---

## 命令一覧

| Brainf*ck | 意味      | UiLang 命令 |
| --------- | ------- | --------- |
| `>`       | ポインタ右   | はい次〜      |
| `<`       | ポインタ左   | くぅ〜ん      |
| `+`       | インクリメント | ういこらしょ    |
| `-`       | デクリメント  | やんのか？     |
| `.`       | 出力      | ういビーム     |
| `,`       | 入力      | リスナー募集    |
| `[`       | ループ開始   | は?        |
| `]`       | ループ終了   | 負けないが？    |

---

## 言語仕様（概要）

* メモリモデル：

  * 無限長配列（実装上は 30,000 セル）
  * 各セルは非負整数（Unicodeコードポイント）
* ポインタ：左右に移動可能
* 入力：UTF-8文字列を 1 文字ずつ読み込み
* 出力：セルの値を Unicode 文字として出力
* 命令語以外の文字列はすべて無視（コメント）
