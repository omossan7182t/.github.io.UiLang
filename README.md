# UiLang v1.1

UiLang は、Brainf*ck から着想を得た **チューリング完全なジョークプログラミング言語**です。
本言語は **Brainf*ck との互換性を意図的に持ちません**。

セルの値は **Unicodeコードポイント**として扱われ、日本語を含む UTF-8 文字を直接出力できます。

本プロジェクトは **非公式・非公認のファンメイド作品**であり、実在の人物・団体・公式プロジェクトとは一切関係ありません。

---

## v1.1 仕様凍結について

* v1.0 を **完全互換で保持**
* 日本語出力の圧縮性・可読性を重視した拡張を追加
* 以降、v1.1 を安定仕様（Stable）とする

---

## 特徴

* 🧠 チューリング完全（無限テープ＋ループ）
* 🌏 UTF-8 / Unicode 完全対応（日本語可）
* 🌐 ブラウザのみで実行（GitHub Pages）
* 💬 命令語以外はすべてコメント扱い
* 🎭 ネタ言語だが仕様は厳密

---

## メモリモデル

* 無限長テープ（実装上は 30,000 セル）
* 各セルは **非負整数（Unicodeコードポイント）**
* 数値はラップしない（8bit制限なし）
* 出力は `String.fromCodePoint` を使用

---

## 命令一覧（v1.1）

### 基本操作

| 概念    | 命令     | 説明                   |
| ----- | ------ | -------------------- |
| ポインタ右 | はい次〜   | 次のセルへ移動              |
| ポインタ左 | くぅ〜ん   | 前のセルへ移動              |
| 加算    | ういこらしょ | 現在セルを +1             |
| 減算    | やんのか？  | 現在セルを -1（0未満不可）      |
| 出力    | ういビーム  | セル値を Unicode 文字として出力 |
| 入力    | リスナー募集 | 入力から 1 文字読み込み        |

---

### ループ制御

| 概念    | 命令     | 説明                      |
| ----- | ------ | ----------------------- |
| ループ開始 | は?     | セルが 0 なら対応する負けないが？へジャンプ |
| ループ終了 | 負けないが？ | セルが 0 でなければ は? に戻る      |

## v1.1 拡張命令

### 明示ゼロ化

**寝な！**
現在セルを 0 に設定する。

---

### 基準点生成

**16歳だぞ**
現在セルを **16** に設定する。

用途：

* ASCII / Unicode 構築の基点
* 乗算ループの初期値

---

### 高頻度差分ショートカット

**きゃっきゃっ**
現在セルを **+5** する。

（= ういこらしょ ×5）

---

### 測値ロード（即値ロード）

**ここで会ったが<n>年目**
現在セルに数値 n を直接代入する。

```text
ここで会ったが12375年目
```

---

### 乗算ループ短縮

**テトリス<回数>：<加算値>位**

意味：

* 現在セルを回数として使用
* 隣接セルに `<回数> × <加算値>` を加算
* 現在セルは 0 に戻る

疑似コード：

```js
while (cell[p] > 0) {
  cell[p]--
  cell[p+1] += 加算値
}
```

## English Note

UiLang is a joke programming language inspired by Brainf*ck but intentionally incompatible with it.
Each cell stores a Unicode code point, allowing direct UTF-8 output including Japanese characters.
