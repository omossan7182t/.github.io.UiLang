# UiLang

**UiLang v1.0 (Frozen)**

UiLang は、Brainf*ck に着想を得た **差分型・Unicode 指向・チューリング完全なジョークプログラミング言語**です。

本言語は **Brainf*ck との互換性を意図的に持ちません**。セルの値を Unicode コードポイントとして扱うことで、日本語を含む UTF-8 文字列を直接出力できます。

本プロジェクトは **非公式・非公認のファンメイド作品**であり、実在の人物・団体・公式プロジェクトとは一切関係ありません。

## 特徴

* 🧠 チューリング完全（無限テープ＋ループ）
* 🌏 Unicode / UTF-8 完全対応（日本語出力可）
* 📐 差分積み上げ方式のセル操作
* 🌐 ブラウザのみで実行可能（GitHub Pages）
* 💬 命令語以外はすべてコメント扱い
* 🎭 ネタ言語だが仕様は厳密

---

## 実行モデル

### メモリ

* 無限長テープ（実装上は十分に大きな配列）
* 各セルは **符号付き整数**
* 初期値はすべて `0`
* オーバーフロー・ラップは行わない

### ポインタ

* 初期位置は `0`
* 左右移動可能
* 範囲外アクセス時の挙動は実装依存（通常はクランプ）

---

## 命令一覧（v1.0 固定）

| 概念    | 命令     | 説明                      |
| ----- | ------ | ----------------------- |
| ポインタ右 | はい次〜   | 現在ポインタを右へ移動             |
| ポインタ左 | くぅ〜ん   | 現在ポインタを左へ移動             |
| 加算    | ういこらしょ | 現在セルを +1                |
| 減算    | やんのか？  | 現在セルを -1（クランプなし）        |
| 出力    | ういビーム  | セル値を Unicode 文字として出力    |
| 入力    | リスナー募集 | 標準入力から 1 文字読み込み         |
| ループ開始 | は?     | セルが 0 の場合、対応する ] までジャンプ |
| ループ終了 | 負けないが？ | セルが 0 でなければ対応する [ に戻る   |

---

## 文法ルール

* 命令語以外の文字列はすべてコメント
* 改行・空白・装飾テキストを自由に含めてよい
* 命令は **完全一致トークン**として認識される

---

## 設計思想（v1.0 凍結）

UiLang は以下を採用します：

* 差分積み上げによる文字生成
* Unicode を第一級市民として扱う設計
* 可視化・教育用途を意識した単純な実行モデル

UiLang は以下を採用しません：

* Brainf*ck 互換性
* 8bit セル制限
* 自動セルリセット
* 暗黙的な安全クランプ

## 互換性について

UiLang は Brainf*ck に着想を得ていますが、

* セル仕様
* 数値モデル
* 文字出力方式

が根本的に異なるため **互換性はありません**。

---

## English Note

UiLang is a joke programming language inspired by Brainf*ck, but **not compatible with it**.
Each memory cell stores a signed integer representing a Unicode code point, enabling direct UTF-8 output.
