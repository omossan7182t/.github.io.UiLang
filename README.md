# UiLang README

Version 1.1（v1.0 互換）

UiLang（ういらんぐ）は、自然言語（主にしぐれうい語録風表現）を用いてプログラムを書く教育用・実験用言語です。

— 冗長でも、回り道でも、意味が分かることを優先する —

---

## 実行モデル概要

UiLang は行単位で命令を解釈します。内部的には数値レジスタ（ACC）と出力バッファ（OUT）を持ち、すべての命令は内部命令へ正規化された後に実行されます。

初期状態
ACC = 0
OUT = ""

---

## 内部命令セット（v1.1）

LOAD n   : ACC に n を代入
CLEAR   : ACC を 0 にする
INC     : ACC を +1
ADD n   : ACC に n を加算
MUL a b : ACC に a × b を加算
PRINT   : ACC を Unicode 文字として出力
NOP     : 何もしない

---

## UiLang → 内部命令変換表

【数値操作系】
ここで会ったがNN年目 → LOAD NN（測値ロード）
寝な！ → CLEAR（明示ゼロ化）
きゃっきゃっ → INC（高頻度差分）
16歳だぞ → LOAD 16（基準点生成）
テトリスA：B位 → MUL A B（乗算ループ短縮）

【出力系】
ういビーム → PRINT（Unicode出力）

【その他】
はい次〜 → NOP（無操作）

---

## v1.0 / v1.1 互換ポリシー

UiLang は後方互換を維持します。

・v1.0 の全命令は v1.1 でも有効
・v1.0 命令は糖衣構文として扱われる
・実行前に必ず v1.1 内部命令へ正規化

未定義命令は無視され、実行エラーにはなりません。

---

## Unicode 出力仕様

PRINT 命令は ACC を Unicode code point として解釈し、対応する文字を出力します。

範囲外の場合は代替文字（�）を出力します。

数値と文字の関係を体感的に理解することを目的としています。
