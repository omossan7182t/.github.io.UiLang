# UiLang

UiLang は、Brainf*ck から着想を得た **チューリング完全なジョークプログラミング言語**です。
本言語は **Brainf*ck との互換性を意図的に持ちません**。

セルの値は **Unicodeコードポイント**として扱われ、日本語を含む UTF-8 文字を直接出力できます。

本プロジェクトは **非公式・非公認のファンメイド作品**であり、実在の人物・団体・公式プロジェクトとは一切関係ありません。

---

## 特徴

* 🧠 チューリング完全（無限テープ＋ループ）
* 🌏 UTF-8 / Unicode 対応（日本語出力可）
* 🌐 ブラウザのみで実行（GitHub Pages）
* 💬 命令語以外はすべてコメント扱い
* 🎭 ネタ言語だが仕様は明確

---

## 命令一覧

| 概念    | UiLang 命令 | 説明                    |
| ----- | --------- | --------------------- |
| ポインタ右 | はい次〜      | 次のセルへ移動               |
| ポインタ左 | くぅ〜ん      | 前のセルへ移動               |
| 加算    | ういこらしょ    | 現在セルを +1              |
| 減算    | やんのか？     | 現在セルを -1（0未満にならない）    |
| 出力    | ういビーム     | セル値を Unicode 文字として出力  |
| 入力    | リスナー募集    | 入力から 1 文字読み込み         |
| ループ開始 | は?        | セルが 0 なら対応する ] までジャンプ |
| ループ終了 | 負けないが？    | セルが 0 でなければ対応する [ に戻る |

---

## 言語仕様

* メモリモデル

  * 無限長テープ（実装上は 30,000 セル）
  * 各セルは **非負整数（Unicodeコードポイント）**
* 数値は **ラップしない**（8bit制限なし）
* 出力は `String.fromCodePoint` により UTF-8 文字として表示
* Brainf*ck 既存コードとの互換性はありません

## サンプル

### 最小出力例（可視文字）

以下は **可視文字 `!` を出力する最小コード** です。

```text
ういこらしょ
（上記を33回繰り返す）
ういビーム
```

## English Note

UiLang is an experimental joke programming language inspired by Brainf*ck, but **not compatible with it**.
Each memory cell stores a Unicode code point, allowing direct UTF-8 output.
