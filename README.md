UiLang README

Version 1.1（v1.0 互換）

1. UiLangとは

UiLang（ういらんぐ）は、
自然言語（主にしぐれうい語録風表現）を用いてプログラムを書く教育用・実験用言語です。

文法は日本語

行単位で命令を解釈

内部的には単純な数値レジスタと Unicode 出力を扱います

わざと遠回りな書き方を推奨します

2. 実行モデル概要

UiLang は以下の構造で動作します。

ソースコード
  ↓
【互換正規化フェーズ】
  ↓
内部命令列（v1.1）
  ↓
実行（レジスタ操作・出力）

内部状態
名前	内容
ACC	数値レジスタ（整数）
OUT	出力バッファ

初期状態：

ACC = 0
OUT = ""

3. 内部命令セット（v1.1）

UiLang はすべての命令を、最終的に以下の内部命令へ変換して実行します。

内部命令	意味
LOAD n	ACC に n を代入
CLEAR	ACC を 0 にする
INC	ACC を +1
ADD n	ACC に n を加算
MUL a b	ACC に a × b を加算
PRINT	ACC を Unicode 文字として出力
NOP	何もしない
4. UiLang → 内部命令変換表
4.1 数値操作系
UiLang命令	内部命令	説明
ここで会ったがNN年目	LOAD NN	測値ロード
寝な！	CLEAR	明示的ゼロ化
きゃっきゃっ	INC	高頻度差分
16歳だぞ	LOAD 16	基準点生成
テトリスA：B位	MUL A B	乗算ループ短縮
4.2 出力系
UiLang命令	内部命令	説明
ういビーム	PRINT	Unicode出力

※ 行内に含まれていれば有効（冗長表現可）

4.3 制御・その他
UiLang命令	内部命令	説明
はい次〜	NOP	明示的無操作
5. v1.0 / v1.1 互換ポリシー
5.1 基本方針

UiLang は後方互換を維持する

v1.0 の全命令は v1.1 でも有効

v1.0 命令は **糖衣構文（シンタックスシュガー）**として扱う

実行前に v1.1 の内部命令へ正規化される

5.2 互換の実現方法
v1.0 命令
  ↓
正規化ルール適用
  ↓
v1.1 内部命令


例：

ここで会ったが72年目
↓
LOAD 72

ういビーム
↓
PRINT

5.3 非互換が起きない理由

命令はすべて 行単位

未定義命令は「無視」される

内部命令セットは拡張のみ（削除しない）

6. Unicode 出力仕様

PRINT は ACC を Unicode code point として解釈

String.fromCodePoint(ACC) 相当

範囲外の場合は代替文字（�）を出力

教育的意図

数値と文字の関係を体感する

ASCII / Unicode の理解を促す

「なぜ出ないか」を考えさせる
